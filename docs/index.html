Federal Funding Finder

A free, open-source, read-only MCP server for SBIR/STTR and federal grants. It searches Grants.gov, NIH RePORTER and the NSF Award Search API, and every result links back to its source.

Connect

Add the server URL to your MCP client.

{
  "mcpServers": {
    "funding-finder": { "url": "https://grants.thelconsulting.com/mcp" }
  }
}

To run it yourself, use npm run dev (Netlify CLI) and http://localhost:8888/mcp.

Example prompts
  • NIH SBIR awards to South Dakota companies since 2020

  • NSF SBIR awards in South Dakota
